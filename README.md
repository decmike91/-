# GestSP Mobile

Version Android simplifiée de GestSP pour le SharePoint CEA Collab : consulter, ajouter des fichiers et des photos,
poser des indicateurs, rechercher et valider les relectures.

- Projet Android : dossier [`gsp Android`](gsp%20Android/) — voir [`gsp Android/LISEZMOI.md`](gsp%20Android/LISEZMOI.md).
- L'APK est construit automatiquement par GitHub Actions (onglet **Actions** › dernière exécution ›
  artefact **GestSP-Mobile-apk**).
